# 家具正面素材生成

将家具、软装、植物与装饰生成一张正面游戏精灵图。使用内置生图工具；不要用脚本绘制、拼接、旋转或像素化素材。

以下规范即为本 Skill 的内置规则；生成前必须完整遵守。

## 视觉母版

仅将 `assets/figure-1-front-orthographic-master.png` 作为正式生图参考图传入。它是视角和像素处理的硬性锁定，不负责家具类别、数量、布局、材质或颜色。

不得把真实家具或房间照片传入生图工具。它们只能用于撰写规范所定义的家具身份信息。

## 固定提示词

每次生成或编辑提示词，均须将以下内容逐字置于最前：

~~~text
严格按照图1的2.5d正交俯视视角；画面中的水平线和垂直线必须保持平行。
所有家具必须正面朝前，主要功能面正对画面；左右结构等宽对称，不出现斜向侧面或3/4产品展示。
采用图1的中等细致度低分辨率游戏精灵像素风：清晰像素阶梯和完整对应主色加深的像素描边；大色块配2–3级硬边明暗；只保留规整、可读的结构纹理。不要连续渐变、柔光、抗锯齿、噪点或写实材质贴图。
后续家具描述只定义家具内容；所有材质、结构和装饰都必须严格服从以上固定视角与像素风格，若有冲突以上述固定提示词为准。
~~~

## 家具内容与参考图职责

- 图1是唯一正式视觉输入和硬性锁定：视角、投影、像素密度、描边和明暗必须与其一致。图1不决定家具类别、数量、材质、颜色或布局。
- 用户提供的家具或房间照片，视觉风格权重为零、家具身份权重为全部。完整继承其中家具的类别、数量、颜色、材质和结构；绝不继承其视角、透视、光照、像素风格、场景、背景、文字或水印。不得把该照片传入生图工具。
- 没有来源照片时，按用户指定风格定义完整家具套组；未指定数量时，生成至少9件。
- 地毯是唯一视角例外：必须采用纯俯视正交平铺。

对应提示词只定义家具身份信息。删除或改写会造成透视、旋转展示或写实渲染的词语，例如侧视、斜视、3/4视角、透视、广角镜头、相机、房间摆放、柔光、反射、镜面高光、阴影、环境光、写实材质和摄影纹理。

不要把家具压缩成普通圆角几何块。每件家具都要有明确的独特轮廓、主要结构、材质、主色、点缀色，以及1–3项低密度且可读的特征，例如分层、接缝、嵌入、面板、包边、开口、纽扣或大面积图案。用大色块和简化轮廓表现材质与结构；避免重复微小网格、单根编织和摄影式阴影。使用来源照片时，完整保留家具身份，同时将细碎表面细节转换为保留辨识度的最低密度可读表现。

## 工作流程

1. 阅读本 Skill 和用户当前请求。
2. 构建提示词，并将固定提示词逐字放在开头。
3. 在加入家具清单前，完成本 Skill 中的冲突避让检查。
4. 生成一张候选精灵图；所有物件完整露出、彼此不重叠，背景为不透明 `#00FF00` 绿色。
5. 检查视角、像素处理、家具身份、数量和输出约束。除非用户明确要求且通过全部检查，否则不要保存候选图。

若用户要求生成朝右版本，不要使用本 Skill；改用独立的朝右家具流程。

## 输出与验收

- 所有列出的物件必须完整露出、互不重叠，并按清晰网格排列；背景必须完全均匀、不透明，使用 `#00FF00 / RGB(0,255,0)`。
- 禁止文字、数字、格线、房间场景、地面、投影、边框、透明或棋盘格背景、水印、人物、宠物和未列出的物件。
- 除地毯外，每件物件都必须保持图1的正面正交关系：水平线与垂直线保持平行，不得出现斜向侧面或3/4产品展示。
- 像素阶梯、与主色对应的深色描边、2–3级硬边明暗和细节密度必须与图1一致。
- 每件用户要求或从来源照片提取的家具，其身份、数量、颜色、材质和结构都正确。

若视角或像素处理不合格，必须从零重新生成整张候选图。若仅部分家具不合格，只编辑失败物件，并锁定每件已正确物件的身份、形状、颜色、材质、数量、位置、比例、像素密度和描边。每次编辑后都要重新检查整张图。
