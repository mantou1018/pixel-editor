# 《我的家》动物精灵规则

## 输出形态

- 动物是角色精灵，不是家具、贴纸或场景插画。
- 默认输出为一张不透明 PNG `sprite sheet`，使用 2×2 四宫格。
- 默认顺序：左上站姿、右上坐姿、左下清醒趴地、右下闭眼睡觉。格间留出清楚的绿幕空隙。
- 用户要求走路、奔跑、舔毛、吐舌等额外动作时，单独生成，不混入默认四格。

## 参考图边界

`animal-view-style-reference.png` 只能作为以下两项参考：

1. 接近平视、轻微斜前视的角色镜头：脸部清楚，身体略侧向；不是俯视，不展示大块头顶或背部。
2. 真实 32×32 小精灵放大后的硬边像素颗粒度。

参考图不能影响主体品种、外形比例、耳朵、尾巴、花色、五官、表情、动作姿势、构图或动作表排布。动物主体特征由用户要求决定；四格动作和顺序由本规则决定。

## 跨帧一致性

四格必须始终是同一只动物：

- 相同体型和头身比例、耳朵、尾巴、花色/斑纹、项圈或配饰；
- 相同镜头、朝向、像素密度和描边逻辑；
- 只改变站、坐、趴、睡姿态，以及必要的遮挡关系。

## 像素和配色

- 按真实 32×32 小图控制：低分辨率、块状、硬边、可读轮廓、2–4 个主要色块、少量大块明暗。
- 只保留头、耳朵、身体、尾巴、鼻子和眼睛等识别形状。不要细碎毛发、睫毛、脸颊红晕、复杂高光、渐变阴影或细小爪子纹理。
- 描边用对应毛色或花纹深一档，避免纯黑或近黑的粗重描边。
- 醒着时的眼睛是 `1×2` 或 `2×1` 深色小长方块；不要圆眼、眼白、反光或水汪汪效果。睡觉时用短小闭眼线。

## 背景与禁止项

- 画面和空隙区域统一为 `#00FF00 / RGB(0,255,0)`，不透明。
- 不要透明、棋盘格、白底、灰底、灰色投影、地面、床、毯子、场景、文字、UI、边框或水印。
- 不要写实、3D、绘画感、高分辨率像素插画、抗锯齿、软边或复杂光影。

## 提示词骨架

```text
[动物主体：品种、花色、耳朵、尾巴、眼睛、配饰]，生成一张 2×2 四姿态像素宠物素材表：左上自然站姿，右上自然坐姿，左下清醒趴地，右下闭眼睡觉；不生成多方向九宫格或额外动作。

四格必须是同一只动物，保持相同的体型、花色、耳朵、尾巴、头身比例、配饰、镜头和朝向；只改变姿态。镜头接近平视并轻微斜前方，脸部清楚可见、身体略侧向；不是俯视。

只参考 animal-view-style-reference.png 的镜头和 32×32 像素颗粒度，不参考其中动物的外形、动作、表情、构图或排布。真实 32×32 小精灵最近邻放大效果，低细节、2–4 个主要色块、硬边像素。醒着时眼睛是无高光的小号深色长方形豆豆眼；描边为同色深一档。

全画面与格间空隙均为不透明 #00FF00 绿幕。不要场景、地面、阴影、贴纸白边、透明背景、文字、UI、水印、抗锯齿、写实或高精细像素插画。
```

## 验收与修正

| 发现的问题 | 单点修正 |
| --- | --- |
| 变成俯视或三视图 | 强调“接近平视、轻微斜前方；不是俯视，也不是平面三视图”。 |
| 长得像参考图中的动物 | 重申“参考图仅限镜头和像素颗粒度”，并补强目标动物的耳朵、尾巴、体型和花色。 |
| 四格不是同一只动物 | 强调“相同花色、耳朵、尾巴、比例、朝向，只改变姿态”。 |
| 过于精细或像插画 | 强调“真实 32×32 最近邻放大、2–4 个主色块、无细碎纹理”。 |
| 背景或描边不合格 | 重申“整张图 #00FF00 不透明绿幕；描边同色深一档，非纯黑”。 |
